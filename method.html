Method

How I build with AI

Claude Code, GitHub Copilot and Codex do the typing. I own the questions, the plan and the checks, which is where quality comes from.

Four steps, every project

  1. 1

    Interview

    The AI asks the hard questions first, then writes a spec with scope, edge cases and what stays out.

  2. 2

    Plan

    Files, interfaces and risks are agreed before any code is written.

  3. 3

    Build

    Agents work in parallel on separate branches while I review direction, not keystrokes.

  4. 4

    Verify

    Tests, builds and screenshots decide when work is done. A fresh reviewer agent checks the result.

The rule behind it: give the AI a check it can run, and never accept "looks done". Repeated tasks become reusable skills and scripts, so each project makes the next one faster.
