Free hosting on GitHub Pages
1. Create a public repository named JaneWambuiKungu.github.io
2. Upload every file in this folder (Add file > Upload files)
3. Settings > Pages > Deploy from branch main / root
4. Visit https://janewambuikungu.github.io after a minute or two
Booking link: open site.js and paste your booking URL into BOOKING_URL.
Colours: edit the variables at the top of style.css.
